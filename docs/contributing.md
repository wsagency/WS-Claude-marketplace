# Contributing

We welcome bug reports, feature requests, and new plugins to the WS Claude Marketplace.

## Reporting bugs

Found something broken? Please file an issue on GitHub with the following details:

- **Steps to reproduce** — what did you do?
- **Expected behavior** — what should happen?
- **Actual behavior** — what happened instead?
- **Plugin name and version** — which plugin, and which version from the marketplace?
- **Claude Code version** — run `claude --version`
- **OS and shell** — macOS/Linux/Windows, bash/zsh/etc.

File your report here: https://github.com/wsagency/WS-Claude-marketplace/issues

## Requesting a plugin or feature

Have an idea for a new plugin? Check the existing set first to avoid duplication:

- **docs-agent** — documentation generation, ADRs, changelogs, style guides
- **ws-commit-commands** — Jira-aware git workflows via jira-cli (status, commit, PR, ticket writing)
- **ws-project-hub** — monorepo scanning and project discovery

If your idea is new, please open an issue with:

- A clear name and one-line description
- What problem it solves
- How it complements (or differs from) existing plugins
- A rough sketch of its commands or agents

## Asking questions

Have a question about how to use the marketplace or a plugin?

- **GitHub Discussions** — https://github.com/wsagency/WS-Claude-marketplace/discussions
- **WS internal Slack** — #claude-marketplace channel
