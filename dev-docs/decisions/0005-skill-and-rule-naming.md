# 0005 — Skill and omp-rule naming rule

- Status: accepted
- Date: 2026-07-27

Skills: `ws-` prefix marks WS graph/flow skills (ws-tdd, ws-implement, …);
unprefixed marks vendored/generic standards and cross-cutting conventions
(adr, diataxis, keep-a-changelog, dual-track-docs, project-hub-conventions,
herdr). `ws-jira-conventions` is grandfathered; `ws-artefacts-explained`'s
prefix is the product name. omp rules follow the same idea: `ws-*` =
WS-convention enforcement (guard-git, commit-format, generated-files),
tool/topic-named = discipline/watcher rules (omp-edge-discipline,
openwiki-freshness). No renames — this records the rule for future names.
