## Question

What recurring process keeps vendored and in-house skill sets current, and who owns it? Settle the trigger (calendar cadence, upstream release signal, or session-time drift detection), the human or role accountable for each set, how a detected upstream change is reviewed before it lands (diff review, ADR when a convention shifts, changelog treatment), how local WS modifications to a vendored set survive an update, and what state the repository must track for the process to be resumable rather than remembered.
