# Domain Documentation

The domain layout is configured at `domain.layout` in `.wsagency/config.yaml`. For `single_context`, read root `CONTEXT.md` and repository ADRs under `dev-docs/decisions/` before changing domain behavior. For `multi_context`, read root `CONTEXT-MAP.md`, then the relevant context file and its nearest decisions directory.

Use the glossary's established vocabulary in tickets, tests, code, and documentation. If a change contradicts an ADR, name the conflict rather than silently overriding it. Missing domain terms and decisions are recorded when they crystallize; setup does not invent product language.
