# Documentation Templates

## Tutorial Template

```markdown
# Tutorial: [Building/Creating/Learning X]

Learn how to [what they'll accomplish] by [approach].

## What You'll Build

[Screenshot or description of the end result]

## What You'll Learn

- [Skill/concept 1]
- [Skill/concept 2]
- [Skill/concept 3]

## Prerequisites

- [Required knowledge]
- [Required software]
- [Required accounts/access]

## Step 1: [Setting Up]

Let's start by [first action].

[Code/commands]

You should see [expected output].

## Step 2: [Building the Foundation]

Now we'll [next action].

[Code/commands]

[Explanation of what happened]

## Step 3: [Adding Features]

[Continue pattern...]

## Step N: [Final Step]

[Last action to complete the project]

## What's Next?

Congratulations! You've learned how to [summary].

To continue learning:
- [Next tutorial]
- [Related how-to]
- [Reference documentation]
```
